# أكاديمية أوروك — Uruk Academy

**منصّة تعليمية تفاعلية مفتوحة المصدر للطلاب العراقيين** — عربية أولًا، تعمل بالكامل
دون إنترنت بعد أول تحميل، وكل تقدّم الطالب محفوظ على جهازه فقط.

🔗 **الموقع الحي:** https://uruk-academy.vercel.app

أكاديمية أوروك هي المشروع الثالث في ثلاثية أوروك مفتوحة المصدر
(بعد [Uruk Cut](https://github.com/dolanexeee/uruk-cut) و[Uruk OS](https://github.com/dolanexeee/uruk-os)).

## ماذا يوجد الآن؟ (الكتب الستة مكتملة)

**المنصة كاملة: ١٩٦ درسًا · ٨٨٤ بطاقة مراجعة · ٦٣٠ سؤال اختبارات ·
٤٦٤ سؤال امتحانات · ٦ امتحانات وزارية شاملة** — وكل مادة متاحة بالكامل،
لا شيء موسومًا «قريبًا».

- **اللغة الإنجليزية — السادس الإعدادي**: كتاب «English for Iraq» **كاملًا بكل وحداته الثماني**:
  ٦ وحدات تعليمية كاملة (لكل وحدة ٤ دروس + اختبار ١٤ سؤالًا بتصحيح فوري وشرح عربي +
  بطاقات لايتنر + امتحان مؤقّت ١٥ سؤالًا / ٦٠ درجة)، ووحدتا مراجعة كما في الكتاب نفسه
  (٤ و٨) باختبارات مختلطة وامتحانَي «نصف الكتاب»، وامتحان وزاري شامل
  (٢٥ سؤالًا / ١٠٠ درجة / ٤٥ دقيقة) بتقرير يفصّل النتيجة وحدةً وحدة.
  المجموع: ٢٤ درسًا · ١٢٢ كلمة مفردات.
- **الرياضيات — السادس العلمي**: ٦ فصول · ٢٤ درسًا · ٩٧ بطاقة قوانين ·
  ٧٢ سؤال اختبارات · ٤٨ سؤال امتحانات · امتحان شامل ١٥٠ درجة / ١٨٠ دقيقة.
- **الفيزياء — السادس العلمي**: ٩ فصول **بالطبعة المنقّحة الحالية** (دُمجت الفيزياء
  الحديثة مع النسبية في فصل واحد) · ٣٦ درسًا · ١٥٥ بطاقة · ١٠٨ أسئلة اختبارات ·
  ٧٢ سؤال امتحانات · امتحان شامل ١٤٥ درجة / ١٨٠ دقيقة · ١٢ مخططًا خطيًا أصليًا (SVG).
- **الكيمياء — السادس العلمي**: ٨ فصول · ٣٢ درسًا · ١٣٨ بطاقة · ٩٦ سؤال اختبارات ·
  ٦٤ سؤال امتحانات · امتحان شامل ١٤٥ درجة / ١٨٠ دقيقة · معادلات كيميائية موزونة
  مرسومة بـ mhchem.
- **الأحياء — السادس العلمي**: ٥ فصول **بالطبعة المخفّضة الحالية** · ٢٠ درسًا ·
  ١٢٠ بطاقة تعريف · ٦٠ سؤال اختبارات · ٤٠ سؤال امتحانات · امتحان شامل
  ١٤٥ درجة / ١٨٠ دقيقة · مسائل وراثة محلولة بمربعات بانيت خطوة بخطوة.
- **اللغة العربية — السادس الإعدادي**: ١٥ فصلًا **بالطبعة التكاملية المشتركة بين
  الفرعين**: الأساليب النحوية العشرة بإعراب كامل مسبَّب، و٤ مجموعات أدب، وفصل
  إنشاء موجَّه بسلّم تقييم ذاتي معلن · ٦٠ درسًا · ٢٥٢ بطاقة · ١٨٠ سؤال اختبارات ·
  ١٢٠ سؤال امتحانات · امتحان شامل ١٤٥ درجة / ٢١٠ دقائق بأقسامه الثلاثة
  (قواعد / أدب / إنشاء).

### محرّك المنصة

- **أسئلة مقالية (مكتوبة)** بحل نموذجي و**مفتاح تصحيح** يصحّح به الطالب لنفسه
  نقطةً نقطة — بصراحة معلنة داخل الواجهة: التصحيح ذاتي، ولا ادّعاء بتصحيح آلي.
- **أمثلة محلولة خطوة بخطوة**: خطوات تنكشف تدريجيًا والحل النهائي لا يظهر إلا بعد آخر خطوة.
- **صيغ رياضية وكيميائية حقيقية**: KaTeX للرياضيات والفيزياء، وmhchem للمعادلات الكيميائية — كلها مدمجة وتعمل دون إنترنت.
- **بطاقات لايتنر** (٥ صناديق) بجدولة استحقاق يومية، و**حساب طالب محلي**: إنجاز كل
  كتاب، سلسلة أيام الدراسة، أفضل النتائج — على الجهاز فقط، بلا حسابات ولا خوادم.
- **PWA قابلة للتثبيت** وتعمل offline بالكامل (تطبيق + محتوى + خطوط عربية مدمجة).

## عن المحتوى والمصادر

المحتوى مبني على بنية الكتب المدرسية الرسمية الصادرة عن **وزارة التربية —
جمهورية العراق** للصف السادس الإعدادي (الإنجليزية) والسادس العلمي (بقية المواد)،
وأُعيدت صياغته كدروس تفاعلية أصلية بكلماتنا؛ لم تُنسخ نصوص الكتب حرفيًا.
أسلوب الأسئلة وبنية الأوراق الشاملة يتبعان نماذج الأسئلة المنشورة من الوزارة،
وأوزان الامتحانات الشاملة مزيج تصميمي داخل مديات التوزيعات الرسمية الموثّقة —
وهذا مُعلن في كل ملف امتحان وفي [CONTENT.md](CONTENT.md) الذي يوثّق بنية كل كتاب ومصادره.

## التقنية

Vite + React + TypeScript + Tailwind CSS · KaTeX + mhchem · تخزين محلي
(localStorage) · Service Worker بتخزين مسبق كامل (vite-plugin-pwa) · خطوط
Cairo وIBM Plex Sans Arabic مدمجة · اختبارات Playwright شاملة (٥٢/٥٢) ضد بنية الإنتاج.

```bash
npm install
npm run dev        # تطوير
npm run build      # بناء الإنتاج
npm run preview    # معاينة الإنتاج
npm run test:e2e   # اختبارات Playwright
```

### English summary

**Uruk Academy** is an Arabic-first, offline-first, open-source interactive learning
platform for Iraqi students — the third flagship of the URUK suite. The engine
(lessons player, instant-feedback quizzes, **written questions with model answers and
self-marking rubrics**, step-by-step worked solutions, Leitner flashcards, timed
ministry-style exams with full correction reports, local student profile) now carries
**all six complete 6th-preparatory books**: English for Iraq (8 units incl. the book's
own two revision hubs and a 25-question / 100-mark capstone), Mathematics (6 chapters),
Physics (9 chapters of the current revised print), Chemistry (8 chapters, balanced
equations rendered with mhchem), Biology (5 chapters of the current reduced print,
genetics problems as worked Punnett solutions), and Arabic (15 chapters: ten grammar
styles with full إعراب walkthroughs, literature, and a guided composition chapter) —
**196 lessons, 884 flashcards, 630 chapter-quiz questions, 464 chapter-exam questions,
and six full mock papers totalling 830 offered marks**. All content is rewritten in
our own words from verified curriculum facts, never copied verbatim. Everything runs
on-device; no accounts, no servers, $0 to run.
